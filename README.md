# 🤖 LearnMate Chatbot

LearnMate is a simple AI chatbot built with Streamlit, LangChain, and Mistral AI. It provides a clean interface for interacting with an AI assistant in real time.

## Features

- Interactive chat interface
- Powered by Mistral AI
- Maintains conversation history
- Lightweight and easy to use

## Tech Stack

- Python
- Streamlit
- LangChain
- Mistral AI
- UV

## Setup

Clone the repository:

```bash
git clone https://github.com/shettigarpratham6-web/LearnMate_Chatbot.git
cd LearnMate_Chatbot/chat_bot
```

Install dependencies:

```bash
uv sync
```

Create a `.env` file:

```env
MISTRAL_API_KEY=your_api_key_here
```

Run the application:

```bash
streamlit run main.py
```
